## Mac polish and contributor integrations

- Replaces the Mac quota popup with a native menu: daily usage, remaining quota and account rows; settings control model scope, identity format, unavailable accounts and reset-time display. Opening uses cached data and asynchronous updates.
- Adds homepage per-model estimated costs and a cost-distribution chart (#18). Exact model matching is shared with the native menu and CLI; missing prices are explicitly unpriced and excluded from partial estimates. These are API-equivalent estimates, not a subscription bill.
- Adds optional round-robin selection and sortable candidate accounts (#12). Older configurations retain priority order. Selected accounts can be reordered with pointer or keyboard, with serialized automatic saving.
- Adds startup update notifications, a manual Settings check and a persistent new-version hint (#15). Startup checks can be disabled and a version can be dismissed. The release link is restricted to this repository. Installation is performed from GitHub Releases or Homebrew; automatic download/execution/restart is not implemented.
- Unifies account quota labels, improves native-menu responsiveness and bilingual wording, and removes the experimental client-localization feature.
- CLI corrections stop presenting missing quota windows as 100% and stop estimating history with a default model's rate. Refresh-token input is masked on supported terminals. `current` reports the locally selected account, not verified external credentials.

## Validation and platform limits

The integrated source passed the local production frontend build, 27 synthetic-IPC browser acceptance checks, 125 Rust checks and 14 actual executable CLI smoke checks. Mac PTY acceptance confirmed navigation and masked synthetic input with cancellation; no real credentials or client switching were used in those tests. Final package validation is tied to the tagged commit and requires the complete package set before publication.

macOS development-app and menu acceptance are checked locally on Apple Silicon. Actual Homebrew installation of the previous v4.7.8 public archive succeeded with a custom app directory, but Gatekeeper rejected that app. The final public ZIP/Brew upgrade, Dock/login behaviour and real multi-client switching are distinct checks. Linux GUI acceptance uses real WebKitGTK in CI with synthetic accounts; it does not prove installed-package or real-account behaviour. Windows GUI acceptance is still limited by the runner's WebView2 environment. Windows one-line CLI/package checks do not establish interactive-terminal or GUI acceptance. A CLI-only, platform-library-free Linux binary is not included.

The Homebrew recipe installs `agy-switch` as the single management command; the previous `agy-lite` alias is not retained.

These packages use complete ad-hoc signing on macOS, not Developer ID signing or notarization. Windows packages are not Authenticode signed. Neither checksum verification nor Homebrew installation establishes platform trust. No quarantine-removal or system-security workaround is part of this release.

Smart switching remains opt-in. It rechecks identity, fresh quotas and pending requests before committing. Client/task detection is conservative but does not prove every external task has finished, and running work is not migrated between accounts. Save work before manual switching.
